**To download the application, please click the "Initial Release" in the "Releases" section.**

This application was created to help an engineer at an aerospace/defense contractor search through a folder full of technical product and manual documents (in ‘.pdf’, ‘.doc’, or ‘.docx’ format) using keywords and phrases.
The **user-typed query, keyword, or phrase gets embedded with a free open-source HuggingFace embeddings model called ‘all-MiniLM-L6-v2’ using the langchain framework and compared to a vectorised sqlite database with embeddings of the technical documents also created by the same embeddings model.**
